Подробно описание

Базов интерфейс за всички CLI команди в приложението.

Използва Command Design Pattern, което позволява лесно добавяне на нови команди без промяна по основния цикъл на програмата (Open-Closed Principle).

Членове Функции(методи) Документация

◆ execute()

virtual void Command::execute ( XmlDocument & doc,
const std::string & args )
pure virtual

Изпълнява съответната команда върху подадения XML документ.

Аргументи
docРеференция към текущо заредения XML документ.
argsАргументите на командата, подадени от потребителя (като стринг).

Заменя в ChildCommand, ChildrenCommand, DeleteCommand, NewChildCommand, PrintCommand, SaveAsCommand, SaveCommand, SelectCommand, SetCommand, TextCommand, и XPathCommand.
