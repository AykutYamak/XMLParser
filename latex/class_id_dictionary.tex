\doxysubsection{Detailed Description}
Речник за регистриране и бързо търсене на XML елементи по тяхното ID. 


\begin{DoxyItemize}
\item 
\end{DoxyItemize}

Този клас поддържа плосък списък (вектор) от всички елементи в дървото, които притежават атрибут {\ttfamily id}. Това позволява изпълнението на команди като {\ttfamily select} или {\ttfamily set} да се случва бързо, без нужда от рекурсивно обхождане на цялото XML дърво.
