Имплементирането на собствен итератор енкапсулира (скрива) вътрешното представяне на децата ({\ttfamily std::\+vector\texorpdfstring{$<$}{<}Xml\+Node\texorpdfstring{$\ast$}{*}\texorpdfstring{$>$}{>}}). Най-\/голямото предимство на този клас е, че предоставяйки методите {\ttfamily \doxylink{class_xml_element_a8e5b6bd76bf871f4cc7f97201cfe4f31}{begin()}} и {\ttfamily \doxylink{class_xml_element_a05042dd05d4b727946e16fc8cc9ca4e6}{end()}}, той прави {\ttfamily \doxylink{class_xml_element}{Xml\+Element}} съвместим със стандартните C++ range-\/based for цикли (напр. {\ttfamily for(auto child :\+ \texorpdfstring{$\ast$}{*}element)}). Това прави кода в целия проект много по-\/четим и устойчив на грешки, в сравнение с ръчното индексиране.
