\doxysubsection{Detailed Description}
Базов интерфейс за всички CLI команди в приложението. 

Използва \doxylink{class_command}{Command} Design Pattern, което позволява лесно добавяне на нови команди без промяна по основния цикъл на програмата (Open-\/\+Closed Principle).
